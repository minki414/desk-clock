# v1.8 구현 및 검증 결과

## 바뀐 내용

- 버전 1.8.0, NSIS x64 사용자별 설치형으로 전환했습니다. Setup exe·blockmap·latest.yml을 생성하며 제거 시 앱 데이터를 보존합니다. 자동 게시와 코드 서명은 하지 않습니다.
- 주입 가능한 업데이터 상태 모듈과 IPC/preload API를 추가했습니다. 버튼으로만 확인하며 자동 다운로드·종료 시 설치·사전 릴리스·다운그레이드를 껐습니다. 오류 원문·경로·토큰을 화면이나 로그에 전달하지 않습니다.
- 정보 탭에 ko·zh·en 업데이트 확인·다운로드·진행률·재시작 안내를 추가했습니다. 다운로드 완료 후 설치를 요청하며 타이머 동작·일시정지·울림 중에는 거부합니다. 설치 직전에 밝기를 복구하고 전역 단축키를 해제합니다.
- 자동 실행은 portable 경로를 우선하며 설치판에서는 process.execPath를 사용합니다. DeskClock 등록 이름을 유지합니다. 설치·이관 안내, 릴리스 노트와 게시 절차도 문서화했습니다.

## 의존성 선정

electron-updater는 **6.6.2**로 정확하게 고정했습니다. npm registry의 `npm view electron-updater time --json`으로 공개 시각 **2025-03-10T05:00:55.748Z**를 확인했습니다. 작업일 2026-11-17보다 2주 이상 오래된 안정 6.x 버전이며 electron-builder와 같은 프로젝트의 GitHub provider·NSIS·latest.yml 형식을 지원합니다. builder 26.18.0이 만든 설치 산출물에서도 업데이트 설정과 메타데이터를 정적으로 검증했습니다.

## 시험

A~E 각 단계에서 기존 136개 시험이 통과했고 F·G 단계에서는 추가 시험 포함 141개가 통과했습니다. 재개 지시 후 `npm test`를 한 번 실행한 결과도 **141개 통과, 실패 0개**입니다. 가짜 업데이터 상태 전이·중복/잘못된 요청·미지원 실행·진행률 중복 제거·HTML 제거와 600자 제한·오류 차단, 타이머 세 상태 설치 거부, 설치판 자동 실행 및 동일 이름 이관을 확인했습니다. 기존 i18n 시험으로 세 언어 키와 변수 일치를 확인했습니다.

## 산출물 정리와 후속 확인

초기 메모리 부족으로 중단했던 검증을 조정자의 재개 지시에 따라 완료했습니다. dist 삭제 명령은 자동 승인 검토에서 정책상 거부되어 조정자에게 요청했고, 조정자가 정리한 후 **Setup exe·blockmap·latest.yml 세 파일만** 남은 것을 확인했습니다.

이번 작업 범위의 남은 일은 없습니다. 실제 설치 및 1.8.0 → 다음 버전 업데이트를 처음부터 끝까지 확인하는 일은 사용자 기기에서 수행합니다. 공개 게시·푸시·public-release·gh release는 조정자 담당으로 실행하지 않았습니다.

## 설계와 다른 점·준수 사항

JSON·YAML에는 개정 기록 주석을 넣지 않는 예외를 조정자에게 확인받았으며 변경은 커밋과 이 보고서에 기록했습니다. 그 외 기능 설계 변경은 없습니다. 설치 파일 실행, 실제 앱 키 입력, 사용자 브라우저 실행/종료, 사용자 앱 데이터 접근, 토큰 환경 설정, 푸시·public-release 조작·gh release 실행은 하지 않았습니다.
