## 1. 개요 및 주요 변경 사항

`docs/v1.5-brief.md`의 요구사항 4개 부문(A, B, C, D) 및 빌드 패키징 지시를 전면 구현 완료하였습니다.

### A. 이미 켜진 프로그램: 포그라운드 전환 및 슬롯 창 재사용
- **Win32 API 바인딩 추가 (`src/main/foreground.js`)**:
  - `user32.AllowSetForegroundWindow(ASFW_ANY = -1)` 바인딩 및 슬롯 실행 직전 호출 경로 마련.
  - `IsWindow`, `IsIconic`, `ShowWindow(SW_RESTORE=9 / SW_SHOW=5)`, `SetForegroundWindow`, `BringWindowToTop`, `GetWindowThreadProcessId`, `AttachThreadInput`, `GetCurrentThreadId` 바인딩.
- **슬롯별 창 기억 및 포커스 복원 (`createForeground`)**:
  - 슬롯 실행 시 기억된 HWND가 살아있으면(`isWindowAlive`) 새 프로세스를 띄우지 않고 최소화 복원(`focusWindow`) 후 전면 배치.
  - 포커스 실패 시 `AttachThreadInput` 스레드 결합 fallback 지원.
  - 슬롯 창 재사용 판정 로직을 순수 함수 `decideLaunch({ rememberedAlive, isMinimized })`로 분리하여 단위 테스트 완료.
  - '실행 후 보낼 키' 및 '시계로 돌아오기' 설정이 기존 창을 재사용한 경우에도 동일하게 동작.

### B. N 키 즉시 야간 모드 전환
- **키 라우팅 (`src/renderer/keys.js`)**:
  - 시계 전면 활성 상태에서 `KeyN`(수정키 없음) 입력 시 `night.toggle` 액션 발행.
  - 서랍 열림, 타이머 입력 중, 타이머 알림 울림 중에는 무시. 숫자패드 단축키 꺼짐 여부와 무관하게 동작.
- **야간 강제 전환 및 밝기 제어 (`src/renderer/app.js`, `src/main/system.js`, `src/main/main.js`)**:
  - 야간 강제 토글 시 WMI 최소 밝기 적용 및 다크 모드 강제(`effectiveMode`).
  - 해제 시 원래 모드 및 이전 밝기로 복원. 앱 재시작 시 해제 상태로 시작.
  - 다음 `nightEnd` 시각 경과 시 자동 해제(`nextNightEnd`).
- **UI 및 토스트**:
  - 2초 토스트 안내(`toast.nightOn` / `toast.nightOff`, 한국어·중국어·영어 3개 언어).
  - 단축키 범례(`legendLine`) 및 리시버 프리셋 버튼에 `N 야간`(3개 언어) 추가.

### C. 일정 출처: 캘린더 기반 공유 vs 개인 판정
- **캘린더 공유 설정 저장 (`src/main/store.js`, `src/renderer/settings.js`, `settings.css`)**:
  - 연결 탭의 사람별 캘린더 목록에 '공유' 체크박스 추가(`people[i].calendar.shared: [calendarId...]`).
  - 연결 탭 상단에 공유 일정 표시 라벨 커스텀 입력칸 추가(`sharedLabel`, 최대 6자).
- **출처 4가지 경로 판정 및 정규화 (`src/renderer/model.js`, `src/main/google.js`)**:
  - 경로 1: 동일 캘린더 id를 2명 이상이 선택한 경우 -> 공유.
  - 경로 2: 누구든 해당 캘린더를 '공유'로 체크한 경우 -> 공유.
  - 경로 3: 다른 캘린더지만 `iCalUID`가 2명 이상의 계정에서 일치하는 경우 -> 공유.
  - 경로 4: 시작 시각 및 제목이 일치하는 경우 -> 공유.
  - 그 외: 개인 일정 -> 해당 사용자 이름.
  - 중복 일정 통합 시 공유 판정 우선, 공휴일은 제외.
  - 캘린더 켠 사람이 2명 이상이거나 공유 캘린더가 1개 이상 존재할 때 출처 표시 활성화.
- **알약 스타일 및 테마 반영 (`src/renderer/icons.js`, 6개 테마 css/js)**:
  - 테마 모델 계약에 `whoKind: 'shared' | 'person' | null` 추가.
  - 공유 일정(`data-kind="shared"`): 각 테마 강조색 10~14% 농도 배경의 미니 알약 뱃지.
  - 개인 일정(`data-kind="person"`): 보조색 텍스트(알약 없음).
  - 이번 주 칸 첫 일정의 `firstWho`도 글자만 작게 표시(알약 없음).

### D. 6개 전 테마 정보 완전 표시 및 주간 일정 7칸 정비
- **네이비 (Navy)**:
  - 오른쪽 열의 점 줄을 '요일 / 제목' 2줄 7칸 띠(`grid-template-columns: repeat(7, minmax(0, 1fr))`)로 전면 개편.
  - Pretendard 보조색, 일요일/공휴일 강조색, 첫 일정 말줄임 및 `+n` 표시.
- **리시버 (Receiver)**:
  - '오늘' 창 하단 램프 표시등 줄을 램프 + 요일 + VFD 제목 7칸으로 개편.
  - 넘침 시 말줄임(`text-overflow: ellipsis`) 및 형광표시관 호박색 발광 톤 적용.
- **스탠바이 (Standby)**:
  - 요일 칩 7개를 '요일 + 첫 일정' 2줄 알약 칩으로 확장.
  - 오늘 목록과 시각적 균형을 유지하며 `+n` 표시.
- **바우하우스·섹터·플립**:
  - 기존 주간 일정 칸에 첫 일정 출처(`who`) 및 말줄임 처리 적용.

## 5. 설계와 다른 점 및 개발 판단

1. **Koffi Win32 포인터 타입 선언**:
   - `_Out_opt_ uint32_t *lpdwProcessId`와 같은 SAL 주석 표기는 Koffi에서 유효하지 않은 타입 에러를 발생시키므로 `uintptr_t`로 안전하게 바인딩하고 `0`을 전달하도록 처리하였습니다.
2. **이관 설정 하위 호환성 유지**:
   - v1.4 이전 설정 파일에서 `calendar.shared` 필드가 누락되어 있는 경우 빈 배열을 기본 주입하지 않고 선택적 속성으로 유지하여 기존 `tests/store.test.js`의 객체 엄격 일치(`assert.deepEqual`) 회귀를 방지하고 온전한 하위 호환성을 보장하였습니다.
3. **Sector 회전 레이어 scrollHeight 이슈 대응**:
   - Sector 테마의 바늘 SVG가 720×720 크기에서 CSS 회전(`transform: rotate(...)`)될 때 투명한 외곽 바운딩 박스가 수학적으로 확장되는 현상에 대해, 실제 콘텐츠 요소들(`.r`, `.wk`, `.memo` 등)의 위치를 직접 검사하여 실제 화면상 넘침이 전혀 없음을 정밀 검증하였습니다.

### 1) 리시버 (receiver) 테마
- **주간 요일 글자 크기 정상화**:

  - 요일 라벨을 v1.5 이전과 동일한 15px 각인 서체 톤(`--rc-engrave`, #958e84, 일요일/공휴일 #d9a24a)으로 복구하고 상단 램프 표시등 및 하단 VFD 미니 타이틀(+who, +n)과의 시각적 균형을 확립.

### 2) 스탠바이 (standby) 테마
- **주간 일정 2열 목록화**:
  - w=1350에서 제목이 2글자 수준으로 잘리던 7개 가로 칩을 제거하고, '오늘' 카드의 빈 공간을 활용한 컴팩트 2열 목록으로 개편.
  - 좌측 열 4행(내일부터 4일) + 우측 열 3행(이후 3일), 행 높이 약 26px, 상단 얇은 구분선(`--sb-track`) 배치.
  - 각 행 구성: 요일(굵게, 일요일 레드) + 첫 일정 제목(말줄임) + 작은 who 글자 + `+n` 건수. w=1350에서도 일정 제목이 잘리지 않고 온전하게 가독성 확보.
- **메모 2명 묶음 전폭 수직 적층**:
  - 메모 묶음이 정확히 2개(`data-g="2"`)일 때 좁은 2열 분할 대신 카드 전체 너비를 사용하는 1열 수직 적층으로 변경.
  - 이름표 줄(`gh`) + 최대 3개 항목 + 그룹 간 얇은 구분선 배치. w=1350에서도 "Buy milk and eggs" 등 일반 길이 메모가 말줄임 없이 100% 온전히 표시.
  - 3~4명(`data-c="1"`)일 때만 2×2 격자를 유지하며, 오늘 카드의 여백이 줄어들며 우측 열 전체가 900px 높이 내에 완벽 수용.
