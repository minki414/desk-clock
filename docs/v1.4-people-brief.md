# v1.4 작업 지시 — 사람 여러 명(캘린더·메모)

설계: Opus · 구현: Sonnet · 2026-11-12 사용자 결정.
배경: 사용자는 동거인과 구글 공유 캘린더를 쓰지만 Google Tasks는 계정 간 공유가 안 되어 동거인 메모를 띄울 수 없습니다.

## 결정
1. **사람 목록**(설정 `people`): 1명 기본, 최대 4명. 각 사람 = `{ id, name, google: (사람별 토큰), calendar: { on, ids: [] }, tasks: { on, listId } }`.
   - 구글 연결은 사람마다 따로(OAuth 루프백 그대로, `prompt=select_account consent`로 다른 계정을 고를 수 있게). refresh token은 사람 id별로 safeStorage 암호화 파일에 저장(평문 금지, 기존 원칙 유지). 연결 해제·사람 삭제 시 그 사람 토큰 파일 삭제.
   - **이관**: 기존 단일 구글 연결·캘린더 선택·메모 목록은 사람 1(`name` = 사전의 기본 이름 '사용자 1'/'User 1'/'用户1' 중 현재 언어)로 옮깁니다. 재로그인 불필요. settingsVersion 3.
2. **일정 합치기**: 캘린더를 켠 사람들의 일정을 시간순으로 합칩니다.
   - **중복 판정**: 시작 시각(종일이면 날짜)과 제목(앞뒤 공백 제거 후 완전 일치)이 같으면 같은 일정 → 한 번만 표시. 같은 사람의 여러 캘린더에서 겹쳐도 한 번.
   - **표시**: 캘린더를 켠 사람이 2명 이상일 때만 출처 표시. 2명 이상에게서 온 같은 일정 → '우리'(zh 我们, en Us). 한 사람에게서만 온 일정 → 그 사람 `name`. 1명뿐이면 표시 없음(지금 화면 그대로).
   - 이번 주 칸의 개수·첫 일정도 중복 제거 후 기준.
3. **메모 묶음**: 메모를 켠 사람 순서대로 묶음 `[{ name|null, items:[…최대 3], more }]`. 묶음 사이 얇은 구분선. 이름 라벨은 메모를 켠 사람이 2명 이상일 때만(1명이면 지금처럼 이름 없이 최대 4개).
4. **갱신**: 1분 주기 그대로, 사람마다 (선택 캘린더 수 + 메모 1)건. 한 사람 실패는 그 사람 것만 마지막 값 유지 + 상태 문장에 이름 포함('지수 메모 갱신 실패 · 19:20 기준' 형식, 3언어).

## 테마 계약 변경 (설계자 승인)
- `today[i].who: string|null`, `week[i]`는 그대로(중복 제거된 결과).
- `memos`·`memoMore` → `memoGroups: [{ name: string|null, items: string[], more: number }]`. 하위 호환은 두지 않고 6개 테마를 모두 고칩니다.
- `who` 표시: 제목 뒤 보조색·작은 글자(본문의 0.6~0.7배), 말줄임 시 제목이 먼저 줄고 `who`는 유지. 테마마다 기존 보조 문구 문법을 따름(리시버는 VFD 안 작은 글자, 플립은 행 오른쪽 끝 등).
- 메모 묶음: 이름 라벨은 섹션 소제목보다 한 단계 작은 보조색, 구분선은 1px 보조선(테마의 기존 hairline 색). 메모 칸 높이를 넘지 않게 묶음 수에 따라 묶음당 표시 개수를 줄이고(예: 3명 이상이면 각 2개) '외 n건'으로.
- `docs/theme-contract.md`, `tools/fixtures.js`(2인 예시: 공유 일정 '우리', 개인 일정 이름, 메모 2묶음 + 3인·4인 극단 예시) 갱신.

## 설정창 (연결 탭)
- '사람' 카드 목록: 카드마다 이름 입력, 구글 상태 문장 + 연결/해제, 캘린더 켜기 토글 + 캘린더 체크 목록(목록 불러오기), 메모 켜기 토글 + 메모 목록 선택, 사람 삭제(한 번 더 확인, 사람 1이 유일하면 삭제 불가). 하단 '사람 추가'(4명이면 비활성). 기존 서랍 디자인 결 유지, 3언어.

## 확인
- 단위 시험: 중복 판정(시각·제목 완전 일치, 공백, 종일), '우리'/이름/표시 없음 규칙, 메모 묶음 상한, 이관, 사람별 토큰 파일 분리·삭제, 3언어 사전 키 일치.
- 화면: 6 테마 × 3 언어 × 라이트/다크 × 1350/1600을 2인 예시로, 3·4인 극단 예시는 1600 라이트만. 헤드리스 Edge(ASCII 임시 경로), 직접 보고 고침.
- 실제 앱: 임시 `--user-data-dir` + 슬롯 전부 비운 설정으로만, 숫자키 누르지 않기, 브라우저·ChatGPT 실행/종료 금지. 연결 탭 카드 UI를 3언어로 캡처.
