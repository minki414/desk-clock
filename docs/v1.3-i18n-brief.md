# v1.3 작업 지시 — 화면 언어 (한국어·中文·English)

설계: Opus · 구현: Sonnet · 2026-11-11 사용자 요청: "설정에서 언어 선택(기본 한국어, 중국어, 영어), 외국어에 맞는 서체로 디자인이 깨지지 않게, 시스템에 있는 글자가 다 바뀌어 보이게."

## 범위
- 설정 `lang`: `'ko'`(기본) | `'zh'`(简体中文) | `'en'`. 바꾸면 즉시 화면 전체가 바뀝니다(재시작 없음). 기존 설정에 없으면 `'ko'`.
- 바뀌어야 하는 것 = **앱이 만든 모든 글자**: 6개 테마의 소제목·빈 상태·'외 n건'·타이머 글자와 해석 힌트(`1분 35초` → `1 min 35 s` / `1分35秒`), 날짜·요일(긴·짧은 형식, 주간 칸 요일), 날씨 상태 이름(WMO 코드 → 각 언어), 상태 문장('캘린더 연결 필요' 등), 단축키 안내 줄의 고정 항목('시계'·'타이머'), 토스트(‘n번 미등록’ 등), 설정창 전체(탭·항목·설명·버튼·확인 문구·'저장됨'), 알림 관련 문구, 날씨 지명(Open-Meteo geocoding `language=ko|zh|en`).
- 바꾸지 않는 것 = 사용자 데이터: 일정·메모 제목, 슬롯 이름(사용자가 입력), 구글 캘린더 이름.
- 문서(README·setup.md)는 한국어 유지. README에 언어 기능 한 줄만.

## 구조
- `src/renderer/i18n.js` 하나에 세 언어 사전과 도우미를 둡니다(번들러 없음, 기존 UMD 방식). `window.ClockI18n = { t(lang, key, vars), fmtDate(lang, date, 'long'|'short'|'dow'|'monthDay'), fmtDuration(lang, ms|{m,s}), weatherLabel(lang, code), langs }`. 메인 프로세스 쪽 문구(토스트·상태)도 같은 파일을 require 해서 씁니다.
- 기존 `labels.js`의 한국어 문구는 이 사전의 `ko`로 옮기고 `labels.js`는 얇은 호환층으로 남기거나 제거(죽은 코드 금지).
- 날짜는 `Intl.DateTimeFormat` 기반, 단 테마별로 시안의 모양을 지킵니다.
  - ko `11월 11일 수요일` / 짧게 `11.11 수`
  - zh `11月11日 星期三` / 짧게 `11.11 周三`
  - en `Wednesday, November 11` / 짧게 `Wed 11.11`
- 테마 계약 변경(설계자 승인): 모델에 `lang`과 `L`(현재 언어로 이미 번역된 고정 문구 객체: today, schedule, week, memo, timer, noEvents, noMemos, noWeather, more(n) 결과 등)을 넣고, 날짜·요일·타이머 힌트·날씨 이름은 핵심 앱이 **이미 형식화한 문자열**로 넘깁니다(`model.dateLong`, `model.dateShort`, `model.week[i].dow`, `model.timer.hint`, `model.weather.label`). 테마 안의 한국어 하드코딩을 모두 없앱니다. 계약 문서(`docs/theme-contract.md`) 갱신.
- 스테이지 루트에 `lang` 속성(`ko`/`zh-CN`/`en`)을 핵심 앱이 붙이고, 설정창 루트에도 같은 값.

## 서체 (깨지지 않게)
- 숫자·라틴 표시용 서체(Jost, Barlow Condensed, Bodoni Moda, Archivo, Nunito, DSEG7)는 언어와 무관하게 유지.
- 한글 자리에 쓰던 서체를 언어별로 교체합니다. `:lang()` 선택자로 테마 CSS의 글꼴 변수만 바꿉니다.
  - 고딕 계열(Pretendard) → zh: **Noto Sans SC**, en: Pretendard 유지(라틴 포함).
  - 명조 계열(Hahmlet, 섹터 다이얼 날짜) → zh: **Noto Serif SC**, en: Hahmlet의 라틴 유지가 어색하면 Bodoni Moda 대신 시안 분위기에 맞는 기존 번들 서체 중 하나로(근거 기록).
  - 리시버 VFD의 글자 줄(한글 부분) → zh: Noto Sans SC 굵게.
- Noto Sans SC·Noto Serif SC는 `@fontsource/noto-sans-sc`·`@fontsource/noto-serif-sc`에서 실제로 쓰는 굵기만(각 2개 이하) `unicode-range` 분할 woff2를 `assets/fonts/`에 넣고 OFL 라이선스 동봉. 외부 CDN 금지. 앱 용량 증가는 보고.
- 영어는 글자가 길어집니다(예: 'This week', 'Wednesday, November 11'). 6개 테마 × 3언어 × 라이트/다크 × w=1350/1600에서 줄바꿈·잘림·겹침이 없어야 합니다. 필요하면 해당 언어에서만 글자 크기를 한 단계 줄이거나 말줄임 — 시안의 비례를 해치지 않는 쪽으로. 중국어는 글자 폭이 넓으니 자간·줄 높이를 확인.

## 확인
- `tools/theme-preview.html`에 `lang=` 파라미터, 예시 모델(fixtures)은 언어 무관 원자료 + 핵심 앱과 같은 형식화 함수로 만들기.
- 헤드리스 Edge 스크린샷(ASCII 임시 경로)으로 6 × 3 × 2(라이트/다크) × 2(1350/1600) 모두 직접 보고 고칩니다. 설정창 각 탭도 3언어로 실제 앱에서 확인.
- 단위 시험: 사전 키 누락 검사(세 언어 키 집합이 같아야 함), 날짜·타이머 힌트·날씨 이름 형식, 설정 기본값·이관.
- 버전 1.3.0, `npm run dist`, 확인 후 공개 저장소 푸시는 설계자가 합니다.
