- 띄운 임시 Edge PID와 그 자식만 종료했고, 남은 임시 Edge 프로세스가 없는 것을 확인했습니다. HTTP 서버를 종료하고 캡처 PNG와 임시 프로필 폴더를 삭제했습니다.

## 감사 후속 수정

- **상태 동기화**: `hotkey:suspend`는 등록 복구가 끝난 뒤 `states()`를 반환합니다. 설정 서랍의 `resumeHotkeys()`가 그 결과로 모든 행의 상태를 갱신하며, 녹화 끝·Esc 취소·서랍 닫힘·탭 이동·행 삭제·기능 변경이 모두 이 경로를 사용합니다. 재등록 실패 때 `taken` 안내가 빈 칸으로 남던 문제를 고쳤습니다.
- **슬롯 중복 실행**: 공통 `runSlot`에서 같은 슬롯의 1500ms 이내 재실행을 무시합니다. 숫자패드와 전역 슬롯 모두 적용되며 설정의 '실행해 보기'인 `force`는 예외입니다. 전역 슬롯의 숫자패드 켬/끔 무시 권한은 `allowWhenDisabled`로 분리해 전역 실행이 중복 제한을 우회하지 않게 했습니다. 초기 후속 수정에서 유지했던 `keys.js` 중복 방지는 아래 재감사 수정에서 제거했습니다.
- **설계 추가 — 전역 키 반복**: 메인이 사용하는 `createDispatcher`는 같은 항목의 400ms 이내 반복을 무시합니다. 항목별로 독립적으로 계산하며 `volumeUp`·`volumeDown`은 반복을 허용합니다.
- **회귀 시험**: `npm test` 135개 통과, 실패 0개입니다. 녹화 복구 6경로는 실제 설정 스크립트에 DOM·shortcut fake를 주입해 모든 행의 문구를 검증했습니다. 메인 IPC의 복구 상태 반환, 슬롯 1500ms 경계·force 예외·전역 실행, 전역 400ms 경계·다른 항목·볼륨 반복도 fake 시간과 deps로 검증했습니다.
- **화면**: 3언어 × 0·3·12행을 다시 캡처하고 직접 열어 겹침·잘림이 없음을 확인했습니다. 영어 0행의 테스트 스크립트 로드 실패는 별도 임시 프로필에서 다시 촬영해 정상 화면을 확인했습니다. fake UI 동작 시험도 통과했습니다.
- **검증 범위**: 실제 창·화면·볼륨·미디어 동작, 실제 앱 실행과 실제 키 입력은 하지 않았습니다. 헤드리스 Edge와 HTTP 서버는 임시 프로필·ASCII 캡처 경로를 사용했으며 자기 실행 PID만 종료했습니다. 남은 임시 Edge 프로세스가 없는 것을 확인하고 HTTP 서버·PNG·임시 프로필을 정리했습니다.
- **재빌드**: 재감사 수정 뒤 `npm run dist` 종료 코드 0, 빌드 후 `npm test` 136개 통과입니다. `win-unpacked`·`builder-debug.yml` 삭제가 완료돼 `dist`에는 `DeskClock-1.7.0-portable.exe`만 있습니다. 최신 크기·해시는 위 '버전·빌드' 절에 반영했습니다. 남은 수정 작업이나 정리 문제는 없습니다.
