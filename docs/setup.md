# 식탁 시계 설치 안내 (LG그램)

이 문서는 사용자 본인이 LG그램에 설치하고 구글을 연결할 때 보는 안내입니다.

## 1. 설치

1. 이 PC에서 `npm run dist`를 실행하면 `dist\DeskClock-1.0.0-portable.exe` 한 파일이 만들어집니다.
2. 이 파일을 LG그램의 원하는 폴더(예: 문서)에 복사합니다. 설치 과정은 없고, 더블클릭하면 전체화면 시계가 시작합니다.
3. 처음 실행하면 Windows가 "PC를 보호했습니다" 화면을 띄울 수 있습니다(서명 없는 개인용 앱이기 때문입니다). **추가 정보** → **실행**을 누릅니다.
4. 설정과 구글 토큰은 `%APPDATA%\DeskClock` 폴더에 저장됩니다. 지우려면 앱을 끄고 이 폴더를 삭제합니다.

## 2. 숫자패드 사용 조건

- **NumLock이 켜져 있어야** 숫자패드 0(어디서든 시계로 복귀)과 +/−(볼륨)이 동작합니다. 꺼져 있으면 Windows가 해당 키를 방향키·Home 등으로 처리하기 때문에 앱이 받을 수 없습니다.
- 시계가 맨 앞일 때만 숫자패드 1~9가 등록한 링크·프로그램을 실행합니다. 다른 창이 앞에 있으면 아무 일도 하지 않습니다.
- 설정에서 숫자패드 단축키를 끄면 0·+·−와 1~9를 모두 가로채지 않습니다. 앱을 끄면 어떤 키도 가로채지 않습니다.

| 키 | 동작 |
|---|---|
| 숫자패드 1~9 | 등록한 슬롯 실행(시계가 맨 앞일 때) |
| 숫자패드 0 | 시계로 복귀(전역). 타이머 입력 중에는 숫자 0, 알림 중에는 끄기 |
| 숫자패드 + / − | 볼륨 올리기·내리기(한 번에 약 4%) |
| T 또는 숫자패드 / | 타이머 입력 열기. 형식은 `분.초`(예: `1.35` = 1분 35초, `10` = 10분, `0.3` = 3초) |
| Enter | 타이머 시작. 동작 중에는 초기화 |
| Space 또는 숫자패드 * | 타이머 일시정지·재개, 알림 끄기 |
| Esc | 타이머 입력 닫기, 설정 닫기 |

## 3. 설정 열기

마우스를 움직이면 오른쪽 아래에 톱니가 3초간 나타납니다. 누르면 설정 서랍이 열립니다. 서랍은 **화면 · 단축키 · 연결 · 정보** 탭으로 나뉘고, 바꾸는 즉시 저장됩니다. 서랍이 열려 있는 동안에는 Esc를 제외한 모든 단축키가 동작하지 않습니다. 앱 종료 단추는 정보 탭에 있습니다(한 번 더 눌러야 종료).

**Windows 시작 시 자동 실행**은 화면 탭에 있습니다. exe를 두는 폴더를 정한 뒤 켜십시오(옮기면 다음 실행 때 새 위치로 다시 등록됩니다). `npm start`로 띄운 개발 실행에서는 쓸 수 없습니다.

## 4. 구글 연결 (캘린더·메모)

LP Lounge에서 쓰는 **기존 Google Cloud 프로젝트**를 그대로 씁니다. 아래 단계는 한 번만 하면 됩니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com)에 접속해 위쪽 프로젝트 선택에서 LP Lounge 프로젝트를 고릅니다.
2. **API 및 서비스 → 라이브러리**에서 다음 두 가지를 검색해 **사용**을 누릅니다.
   - Google Calendar API
   - Google Tasks API
3. **API 및 서비스 → OAuth 동의 화면**(화면에 따라 "Google Auth platform → 데이터 액세스")에서 범위를 추가합니다. 두 가지 모두 읽기 전용입니다.
   - `https://www.googleapis.com/auth/calendar.readonly`
   - `https://www.googleapis.com/auth/tasks.readonly`
4. 같은 메뉴의 **게시 상태**(또는 "대상")를 **프로덕션(In production)** 으로 바꿉니다.
   - 테스트 상태로 두면 7일마다 로그인이 풀려 시계에 "캘린더 연결 필요"가 다시 뜹니다.
5. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**에서 애플리케이션 유형을 **데스크톱 앱**으로 만듭니다. LP Lounge용 데스크톱 클라이언트가 이미 있으면 그것을 다시 써도 됩니다. 웹 애플리케이션 유형은 쓸 수 없습니다.
6. 만든 클라이언트의 **JSON 다운로드**를 눌러 LG그램에 저장합니다. 이 파일은 설정에서 고른 뒤 앱 폴더로 복사되므로 이후 보관 위치는 상관없습니다.
7. 시계 설정 → **연결** 탭 → **구글**에서 **클라이언트 파일 고르기**로 위 파일을 고른 뒤 **구글 로그인**을 누릅니다.
8. 브라우저가 열리면 휴대폰에서 일정·메모를 입력하는 구글 계정으로 로그인합니다. 처음 한 번 "Google에서 확인하지 않은 앱" 경고가 뜨면 **고급 → (프로젝트 이름)(안전하지 않음)으로 이동**을 눌러 허용합니다. 본인이 만든 앱이라 안전합니다.
9. "연결되었습니다" 화면이 나오면 설정으로 돌아와 표시할 캘린더와 메모 목록을 고릅니다. 고르지 않으면 기본 캘린더와 기본 메모 목록을 씁니다. 한국 공휴일을 표시하려면 `대한민국의 휴일` 캘린더를 함께 선택합니다.

연결 해제는 같은 자리의 **연결 해제**입니다. 구글 쪽 권한도 함께 취소하도록 요청합니다.

## 5. 화면에 나오는 안내 문구

| 문구 | 뜻과 조치 |
|---|---|
| 캘린더 연결 필요 | 구글을 아직 연결하지 않았거나 연결이 풀렸습니다. 설정에서 다시 연결합니다. |
| 토큰 보관 불가 | Windows 사용자 계정의 암호화 저장소를 쓸 수 없습니다. 일반 로그인 계정으로 실행합니다. 토큰은 평문으로 저장하지 않습니다. |
| 일정(메모·날씨) 갱신 실패 · 19:20 기준 | 마지막 성공 시각의 정보를 계속 보여 주고 있습니다. 인터넷이 돌아오면 자동으로 다시 가져옵니다. |
| 2번 실행 실패 / 2번 미등록 | 슬롯 주소·경로를 확인합니다. 3초 뒤 사라집니다. |

오른쪽 아래 작은 점은 상태 점입니다. 인터넷이나 설정에 등록한 서버 주소에 문제가 있으면 색이 바뀝니다.

## 6. 날씨 위치와 야간 감광

- 날씨 위치는 처음에 IP 주소로 추정합니다(하루 한 번). 틀리면 설정의 **지명 검색**으로 바꿉니다.
- 야간 감광은 기본으로 켜져 있고, 야간(기본 19:00~07:00)에 노트북 화면 밝기를 최소값으로 낮췄다가 아침에 원래대로 되돌립니다. Windows가 밝기 제어를 지원하지 않는 화면이면 화면 위에 검은 막을 씌우는 방식으로 대신합니다. 앱을 끌 때도 원래 밝기로 되돌립니다.
- 야간에 화면이 너무 어두워 보이면 설정의 **최소 밝기**를 올립니다.

## 7. 알아 둘 점

- 업데이트 재부팅 뒤에도 시계가 다시 뜨게 하려면 설정 → 화면 탭의 **Windows 시작 시 자동 실행**을 켭니다.
- 웹 슬롯은 기본으로 Brave의 기존 프로필을 씁니다. Brave가 없으면 설정에서 Chrome·Edge·기본 브라우저를 고릅니다.
- 프로그램 슬롯에는 `.exe`·`.lnk`·폴더 경로를 그대로 적습니다.
