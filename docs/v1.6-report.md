## 바뀐 것

- **A — 시계 복귀 전역 단축키:** 기본 Ctrl+H, 빈 값은 끔이며 설정 버전은 3을 유지합니다. 조합 정규화·Electron accelerator 변환·충돌 상태·녹화 중 일시 해제와 재개·종료 시 자기 등록만 해제를 구현했습니다. 시계가 포커스이면 무동작이고 다른 앱에서 돌아올 때 기존 키 전송·자동 복귀 대기를 취소하며 창 모드는 유지합니다. 숫자패드 켬/끔과 독립적이고, 화면 아래 범례는 바꾸지 않았습니다.
- **B — 전체화면 버튼:** 모든 테마 공통 좌하단 44px 버튼을 톱니와 대칭으로 배치했습니다. 마우스 이동 후 3초만 표시하고 서랍을 열면 숨깁니다. 전체화면/최대화 창 왕복, 상태 이벤트와 초기 아이콘 동기화, 3언어 접근성 문구를 추가했습니다. 창 모드는 저장하지 않습니다.
- **C — 구글 재로그인:** refresh token 갱신 중 invalid_grant를 expired로 구분하고 토큰을 삭제합니다. 사람별 만료 상태와 계정 힌트를 저장하고 연결 상태 갱신 시 보존합니다. 만료된 사람 카드로 연결 탭을 바로 열고, 경고색 점·계정·다시 로그인 버튼과 기존 선택을 표시합니다. 재로그인 성공 시 만료를 해제하고 primary 캘린더 계정 주소를 갱신하며 자료를 즉시 받아 시계를 앞으로 가져옵니다. 연결 해제 시 만료·계정을 초기화합니다. 메모만 켠 사람의 만료 안내도 표시합니다.
- **문서:** architecture의 단축키 범위·키 라우팅·복귀·설정 서랍을 갱신하고 setup에 Google Auth Platform의 대상(Audience) → 앱 게시 → 프로덕션 전환과 경고 화면 통과·재로그인 절차를 추가했습니다.

## 화면 확인

임시 HTTP 서버와 **새 ASCII 임시 프로필의 headless Edge**로 6개 테마 × 라이트/다크 × 폭 1350/1600(높이 900), 총 **24장**을 촬영하고 PNG를 모두 직접 열었습니다. 각 이미지에서 body.awake 상태, 좌하단 18px·하단 18px·44px 크기·표시 상태를 함께 확인했습니다. 모든 조합에서 아이콘이 읽히고 잘리지 않았으며 테마 글자와 충돌하여 읽기 어려운 곳은 없었습니다. 상태 점 근처의 일시적 오버레이는 톱니와 같은 표시 규칙을 유지합니다. 첫 화면 검증에서 발견한 버튼 숨김 CSS 선택자 오류는 수정 후 전 조합을 다시 검증했습니다.

실제 Electron은 매번 임시 user-data-dir에 슬롯 9개를 비우고 숫자패드 단축키를 끄며 returnHotkey를 빈 값으로 준비한 뒤 실행했습니다. **키 입력 없이 DOM 클릭만** 사용하여 전체화면 → 작업 영역 최대화 창 → 전체화면 왕복과 아이콘 변경을 확인하고, 화면 3장과 서랍 화면 1장을 직접 열었습니다. 기존 fit()으로 가장자리 띠·잘림이 없었습니다. Windows 배율에 따른 1px 미만 좌표 반올림은 화면 결함이 아니므로 검증에 허용했습니다. 서랍을 열면 두 모서리 버튼이 숨는 것도 확인했습니다.

별도 가짜 API의 headless 화면에서 만료 카드 자동 열기·경고색·계정·기존 캘린더/메모 선택을 확인하고 1장을 직접 열었습니다. 녹화의 무효 값 미저장·정상 값 저장·지우기·즉시 탭 이동/서랍 닫힘 때 등록 재개도 확인했습니다. 녹화의 비동기 해제 응답을 기다리는 동안 취소되는 경합도 보완했습니다.

총 29장의 PNG와 임시 프로필·HTTP 서버·검증용 스크립트를 정리했습니다. 사용자가 쓰는 브라우저·ChatGPT 창과 실제 DeskClock 설정 폴더는 건드리지 않았습니다. headless Edge 예외는 조정자의 명시적 허용을 받아 자기 프로필/프로세스만 사용했습니다.

## 못 한 것과 설계와 다른 점

구현에서 빠진 요구 사항은 없습니다. 규칙에 따라 실제 구글 로그인과 실제 전역 단축키의 키 입력 시험은 하지 않았고 가짜 주입 시험으로 확인했습니다. 독립 감사와 릴리스 브랜치 반영·푸시는 조정자에게 남깁니다.

동작 설계는 유지했습니다. 만료되어 목록을 다시 받을 수 없을 때는 저장된 캘린더 ID와 메모 목록을 읽기 전용으로 보여 선택이 사라지지 않게 했습니다. JSON 두 파일에는 주석 문법이 없어 유효한 JSON을 유지하고 개정 내역을 이 보고서에 남겼습니다. HTML·CSS의 개정 기록은 각 언어의 유효한 주석 안에 넣었습니다. 자동 화면 촬영은 페이지·서체 로딩 완료 후 CDP로 캡처하여 미완성 화면을 배제했습니다.

## 감사 후속 수정

- 구글 refresh의 `invalid_grant` 처리를 `createGoogle.onExpired(id)` 한 곳으로 모아 목록 조회·동기화·연결 직후 계정 조회가 모두 만료를 알립니다. 토큰 삭제 후 `markExpired`가 계정을 보존하고 연결 플래그를 다시 계산하여 설정을 전달하며, 이미 만료·미연결이면 중복 전달하지 않습니다.
- 설정 푸시에서 새 만료를 받으면 조작 중에도 카드를 다시 그리고 오래된 목록을 비웁니다. 목록 조회의 실패 반환값은 `null`을 유지하고, 연결 직후 조회에서 발견한 만료도 보존합니다. 동기화의 사람별 격리와 만료 시 정상 재시도 주기는 그대로입니다.
- 가짜 fetch·safe storage의 목록 만료/HTTP 500/네트워크 오류 및 가짜 Electron의 비활성 피드·멱등성/연결 직후 만료 시험 5개를 추가하여 **기존 113개 포함 총 118개 전부 통과**했습니다(`npm.cmd test`). JavaScript 구문 검사와 `git diff --check`도 통과했습니다. 실제 구글 로그인·앱 키 입력·브라우저 실행은 하지 않았습니다.
- `npm.cmd run dist`가 종료 코드 0으로 완료됐고, 패키지 archive의 버전 1.6.0 및 수정된 런타임 파일 3개가 소스와 일치함을 확인했습니다. 새 포터블 실행 파일은 124,401,047바이트이며 SHA-256은 `e362736cce61eb48c9170d87c5559d99b41c1fee0ad8dbe713d2eaf9c429334d`입니다.
