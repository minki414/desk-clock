## 4. 키 라우팅 (대시보드 포커스 상태)

우선순위 순서:

1. 설정 서랍 열림 → 단축키 전부 무시(Esc만 서랍 닫기).
2. 알림 울림(`ringing`) → Enter·NumpadEnter·Space·NumpadMultiply·Numpad0 = 알림 끄기 → 타이머 숨김.
3. 타이머 입력(`input`) → 숫자(상단·숫자패드), `.`(Period·NumpadDecimal), Backspace, Enter=시작 또는 무효 시 `0.00`으로 초기화, Esc=입력 닫기. 숫자패드 1~9는 실행이 아니라 숫자.
4. 타이머 동작/정지(`running`/`paused`) → Space·NumpadMultiply=일시정지/재개, Enter·NumpadEnter=초기화(입력 상태 `0.00`으로).
5. 그 밖 → Numpad1~9 = 슬롯 실행(단축키 켜짐일 때), `T`·NumpadDivide = 타이머 입력 열기.

숫자패드·타이머 키는 시계 창이 포커스일 때만 받습니다. 사용자 단축키는 `globalShortcut` 목록으로 등록하며 Ctrl·Alt·Win 중 하나 또는 수정키 없는 F1~F24가 필요합니다. 숫자패드 단축키 켬/끔과 무관하고 빈 조합은 미등록입니다. 시계로 돌아오기는 이미 포커스면 무동작이며, 아니면 실행 후 키 전송·자동 복귀 대기를 취소하고 `bringToFront()`로 돌아오며 창 모드를 유지합니다. 녹화 중에는 목록 전체를 해제하고 끝·취소·탭 이동·서랍 닫힘 때 복구합니다. 중복·다른 앱 점유·잘못된 조합은 행별 상태로 표시합니다. `Numpad0`=타이머 숫자 0 또는 알림 끄기, 그 밖에는 무동작. `NumpadAdd`/`NumpadSubtract`=`volume` 액션(설정 서랍 열림이면 무시, `e.repeat` 허용).
단축키 끄기: 1~9·볼륨 무시. 타이머(T)는 대시보드 안 기능이라 계속 동작.
키 반복(`e.repeat`)은 슬롯 실행에서 무시(볼륨은 허용), 같은 슬롯 1.5초 내 중복 실행은 메인 공통 실행 경로에서 무시합니다(숫자패드·전역 단축키 공통). 렌더러는 실행 시각을 따로 기록하지 않습니다.

전역 기능은 돌아오기·다른 창 최소화/닫기·볼륨·음소거·미디어·슬롯·타이머·야간 모드·전체화면·화면 끄기입니다. 슬롯은 숫자패드와 `runSlot(n, { force })`를 공유하며, 타이머와 야간 명령은 `keys.js`의 T·N 전이를 공유합니다. 다른 창 처리는 보임·제목·소유/도구/UWP 숨김·시계 PID·바탕화면/작업표시줄 클래스를 순수 함수로 걸러 `PostMessageW`로 요청하며 최소화 시 이미 최소화된 창도 제외합니다. 닫기는 정상 닫기 요청만 보내며 저장 여부는 각 앱이 묻습니다. 화면 끄기도 비동기 `PostMessageW`를 사용합니다.

## 5. 타이머 해석 규칙 (사용자 확정)

- 형식 `분.초`. 소수점 뒤 숫자는 초 그대로: `1.3`=1분 3초, `1.35`=1분 35초, `1.03`=1분 3초, `10`=10분, `0.3`=3초.
- 무효: 초 ≥ 60(`1.60`~`1.99`), 소수 셋째 자리 이상(`0.001`), 합계 0, 빈 입력, 분 4자리 이상.
- 무효로 Enter → 입력 표시를 `0.00`으로 되돌리고 짧게 흔들림 표시, 입력 상태 유지(버리지 않고 다시 입력).
- 입력 중 두 번째 `.`와 7자 초과 입력은 키 자체를 무시.
- 마감 시각은 메인 `timer.js`가 보관(`endAt`)해 렌더러가 가려져 있어도 정확히 울림. 일시정지는 남은 ms 보관.
- 종료: 대시보드를 맨 앞으로(`setAlwaysOnTop(true)→show→focus→setAlwaysOnTop(false)`), 타이머 깜빡임, Web Audio 합성 알림음 반복(최대 3분 후 자동 정지).

## 6. 실행·복귀

- 웹 슬롯: 선택 브라우저의 실행 파일을 레지스트리 `App Paths`·표준 설치 경로 순으로 찾고, `--app=<URL>`로 실행(슬롯별 '주소창 없는 창' 기본 켬). '기본 브라우저'는 `shell.openExternal`.
- 프로그램 슬롯: `.exe`·`.lnk`·폴더를 `shell.openPath`.
- 실행 실패·빈 슬롯: 아무 창도 띄우지 않고 상태 줄에 3초간 '2번 실행 실패' 표시.
- 복귀: 실행 직전 대시보드가 맨 앞이므로, 실행 창을 닫거나 최소화하면 Windows가 다음 창인 대시보드를 활성화합니다. 보조 장치로, 실행 후 10분 동안만 `foreground.js`가 1초마다 확인해 맨 앞이 바탕화면·작업표시줄(`Progman`/`WorkerW`/`Shell_TrayWnd`)이면 대시보드를 앞으로 가져옵니다.
- 실행 후 키 보내기: 슬롯의 선택 항목 `sendKeys`(예: `Ctrl+Alt+Shift+V`, 빈 값=끔)가 올바르면(`keycombo.js` `parseCombo`) 실행 성공 뒤 `foreground.waitStable`이 200ms마다 맨 앞 창을 읽어, 시계 창·`Progman`/`WorkerW`/`Shell_TrayWnd`가 아닌 같은 창이 1000ms 이어지면(`shouldSend`) 700ms를 더 기다려 같은 창이 아직 맨 앞인지 다시 확인(`confirmSend`, 첫 실행이 느린 앱 대비)한 뒤 `system.sendCombo`가 koffi `keybd_event`로 수정키 누름→주 키 누름·뗌→수정키 뗌을 15ms 간격으로 보냅니다. 재확인 대기를 포함해 10초 안에 조건이 안 되면 보내지 않고 '7번 키 보내기 실패'를 3초 표시하며, 다른 슬롯을 실행하면 대기는 취소됩니다. 시계 창에는 절대 보내지 않습니다. 슬롯의 `returnToClock`(기본 끔)이 true이면 키 전송 성공 1500ms 뒤(`sendKeys`가 없으면 같은 안정 판정 뒤, 10초 안에 안 되면 조용히 포기) `bringToFront`로 시계를 앞으로 가져오며, 전송 실패 때는 가져오지 않고 다른 슬롯 실행 시 `cancelWait`로 함께 취소됩니다. 다른 앱은 최소화·종료하지 않습니다.

- 수동 복귀: **사용자 단축키** 목록의 시계로 돌아오기(새 설치 기본 Ctrl+H)로 다른 앱에서 바로 돌아옵니다. 숫자패드 단축키를 꺼도 전역 목록은 별도로 동작합니다.
- 전체화면 끄기: 마우스를 움직이면 톱니와 좌우 대칭인 좌하단에 버튼이 3초 보입니다. 전체화면을 끄면 기본 창 틀을 유지한 최대화 창으로 바뀌어 작업 표시줄이 보이며, 다시 누르면 전체화면입니다. 창 모드는 저장하지 않아 매번 전체화면으로 시작하고, 크기 변경은 기존 `fit()`을 씁니다.

## 7. 갱신·오류

- 갱신 주기: 일정·메모 1분(**캘린더·메모를 켠 사람마다** 선택한 캘린더 수+메모 1건의 요청, 캘린더 목록은 설정에서 불러올 때만 가져옴), 날씨 30분, IP 위치 24시간. 메인 `sync.js`가 담당하고 시작 직후 1회 실행. 자료는 `data.people[id] = { events, tasks, sync }`, 캐시는 `cache.people[id]`(v1.3 이하의 단일 캐시는 사람 1이 이어받음).
- 실패하면 마지막 값을 유지하고 지수 백오프(최대 30분)로 재시도합니다. **사람 단위로 격리**: 한 사람이 실패하면 그 사람 것만 마지막 값을 유지하고 상태 문장에 이름이 붙으며(`지수 메모 갱신 실패 · 19:20 기준`), 스케줄러 백오프는 켠 사람 전원이 실패했을 때만 걸려 한 사람의 문제가 다른 사람의 1분 갱신을 늦추지 않습니다. 상태는 테마 문법 안의 한 줄 안내로만 표시하며 오류 창은 띄우지 않습니다.
- **v1.3→v1.4 이관(사람 1)**: `settingsVersion` 3으로 올라갈 때 옛 단일 구글 연결의 캘린더 선택·메모 목록을 `people[0]`(이름 = 현재 언어의 '사용자 1')으로 옮기고 옛 설정은 `settings.json.v2.bak`으로 한 번 남깁니다. 토큰은 시작 때 `google-token.bin`을 복사→같은 폴더에서 이름 바꾸기(원자적)→내용 비교→옛 파일 삭제 순서로 `google-token-p1.bin`에 옮기며, 실패하면 옛 파일을 건드리지 않고 사람 1이 그 파일을 계속 읽어(재로그인 불필요) 다음 시작에 다시 시도합니다.
- 자정·절전 복귀(`powerMonitor` `resume`) 때 즉시 재갱신합니다.

## 8. 다크모드·야간 감광

설정: 라이트(기본) / 다크 / 자동(야간 19:00~07:00 다크, 시각 변경 가능; 2026-11-11 사용자 결정, 옛 설정은 `settingsVersion` 2 이관 때 한 번 라이트로 바꿈). 전환은 CSS 변수 2초 교차 페이드. 테마마다 라이트·다크 두 벌.
야간 감광(기본 끔 — 2026-11-11 사용자 결정, 옛 설정은 `settingsVersion` 2 이관 때 한 번 끔으로 바꿈; 최소 밝기 기본 0%): 야간 시간대 시작 시 밝기 저장→최소, 끝나면 복구. 앱 종료(`before-quit`) 때도 복구. 비정상 종료 대비로 '감광 중·원래 값'을 settings에 기록해 다음 시작 때 낮이면 복구. 야간 중 사용자가 직접 밝기를 바꾸면 그 값을 존중(다음 전환까지 다시 낮추지 않음).

## 9. 가벼움 예산

- 렌더는 초 경계 정렬 `setTimeout` 1초 1회. 초침 같은 연속 움직임은 CSS `transform` 애니메이션만 사용(합성 스레드).
- 대기 중 목표: CPU 평균 1% 미만, 메모리 250MB 미만(측정해 보고).
- 잔상 방지 이동은 넣지 않습니다(2026-11-11 사용자 지시).

## 10. 설정 서랍 (v1.2 재설계)

마우스를 움직이면 우측 하단에 작은 톱니가 3초간 나타납니다. 누르면 오른쪽에서 폭 520px 서랍이 0.28초 ease-out으로 밀려 나오고(닫기 0.2초), 뒤 화면은 `rgba(0,0,0,.35)`로 어두워집니다(바깥을 누르거나 Esc로 닫음). 마우스 커서는 평소 숨깁니다.
색은 패널 #17171a·구분선 #26262b·본문 #ececef·보조 #9a9aa3·강조 #e8a33d 하나(밝은 모드 없음), 서체는 Pretendard Variable. 저장 버튼은 없고 바꾸는 즉시 저장하며 항목 옆에 0.8초 '저장됨'이 뜹니다.
탭 4개(밑줄형, 방향키로 이동):
- **화면**: 테마 6종(실제 화면 축소 이미지 카드 2열, 현재 색 모드에 맞는 `thumbs/<id>-<light|dark>.webp`) / 색 모드(라이트·다크·자동) / 야간 시간 / 야간 감광 / 최소 밝기(0~30%) / Windows 시작 시 자동 실행.
- **단축키**: 맨 위 사용자 단축키 최대 12행(기능 드롭다운·슬롯 번호·조합·녹화·삭제, 미지정 조합은 꺼짐). 전역 점유 안내·중복/점유/잘못된 조합 안내·다른 창 닫기 경고를 표시하고 하단에서 행을 추가합니다. 녹화 중 전역 목록을 해제하며 끝·취소·탭 이동·서랍 닫힘에 복구합니다. `settingsVersion` 4에서 옛 `returnHotkey`를 한 번 이관하고 키를 제거합니다(옛 빈 값은 빈 목록). 이어서 숫자패드 단축키(0·+·−·1~9 일괄) / 웹 링크 브라우저 / 슬롯 1~9(이름·웹/프로그램·주소 또는 경로·찾아보기·주소창 없는 창·실행해 보기, 빈 슬롯은 흐리게).
- **연결**: 구글(클라이언트 파일 상태·고르기) / 사람(카드 목록, 최대 4명: 이름 입력·구글 상태와 로그인/해제·만료 시 경고색 점/계정 주소/다시 로그인(이전 계정 힌트 사용, 선택 보존)·캘린더 켜기+표시할 캘린더·메모 켜기+메모 목록·사람 삭제(한 번 더 눌러 확인, 한 명뿐이면 불가), 하단 '사람 추가'는 4명이면 비활성) / 날씨 위치(자동·지명 검색) / 감시할 서버(행마다 상태 점, 연결 탭이 열려 있는 동안 15초마다 확인).
- 만료된 사람이 있으면 서랍을 열 때 **연결** 탭과 해당 카드로 이동합니다. refresh token 만료는 `expired`로 구분해 백오프 없이 확인하며, 다른 사람의 갱신은 계속됩니다. 재로그인 성공 시 만료 표시와 계정을 갱신하고 즉시 자료를 받아 시계를 앞으로 가져옵니다.
- **정보**: 버전 / 설정 폴더 열기 / 앱 종료(붉은 외곽선, 한 번 더 눌러 확인).

### 10.1 화면 크기 (v1.2)

## 11. 구현 순서 (Sonnet 단계별, 각 단계 끝에 시험·스크린샷)

1. 뼈대: Electron 창·전체화면·전원 차단·설정 저장·테마 1종(대표) 정적 렌더.

## 12. 자동 실행(v1.2 구현)·제외 항목

- **Windows 시작 시 자동 실행**: 설정 `autoStart`(기본 꺼짐). 켜면 `app.setLoginItemSettings({ openAtLogin: true, path })`. portable exe는 실행할 때마다 임시 폴더에 풀려 `process.execPath`가 임시 경로이므로 **`PORTABLE_EXECUTABLE_FILE`(원래 exe 경로)만** 등록합니다(`src/main/autostart.js`). 그 값이 없으면(`npm start` 개발 실행) 토글을 막고 '설치본에서만 쓸 수 있습니다'를 보입니다. exe를 옮기면 등록 경로가 낡으므로 앱 시작 때 켜져 있으면 현재 경로로 다시 등록합니다. 시작 직후 네트워크가 늦게 잡혀도 마지막 캐시를 보여 주고 §7의 백오프로 회복합니다(`sync.js` 시험 포함).
- 음력·절기 표시: 사용자 결정으로 하지 않습니다.
