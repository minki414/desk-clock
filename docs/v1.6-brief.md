# v1.6 지시서 — 시계로 돌아오기 단축키 · 전체화면 끄기 버튼 · 구글 재로그인

설계: Opus · 구현: Codex · 감사: Codex(구현과 다른 새 작업자)
사용자 요청 원문(2026-11-16): "타 프로그램에 있다가 시계로 돌아올 때 너무 불편해. 컨트롤 에이치 등 단축키로 다시 시계로 돌아올 수 있게 해 주고, 모든 테마 좌하단 등 구석에 전체화면 끄기(하단 작업표시줄 표시) 버튼도 만들어 줘(기본은 전체화면, 상태 저장 X). 구글 7일 인증 만료되면 설정에서 편하게 재인증할 수 있게 해 줘."

## A. 시계로 돌아오기 전역 단축키

설계서 §1·§4의 '전역 단축키 없음'을 **이 한 가지만 예외**로 바꿉니다(숫자패드 단축키는 지금처럼 시계가 맨 앞일 때만).

1. 설정 `returnHotkey`(문자열, `keycombo.js` 형식, 기본 `'Ctrl+H'`, `''`=끔). `store.js` 기본값에 추가하고 정규화: `parseCombo`로 올바르면 `formatCombo` 값, `''`이면 `''`, 그 밖(깨진 값)은 기본값. `settingsVersion`은 올리지 않습니다(새 키라 기본값 병합으로 충분).
2. `keycombo.js`에 순수 함수 `toAccelerator(str)` 추가 → Electron accelerator 문자열 또는 `null`.
   - Ctrl→`Control`, Alt→`Alt`, Shift→`Shift`, Win→`Super`, Esc→`Escape`, Space·Enter·Tab·F1~F24·A~Z·0~9 그대로.
   - **Ctrl·Alt·Win 중 하나 이상이 반드시 있어야** 함(수정키 없음·Shift만은 `null` — 모든 프로그램의 일반 타이핑을 빼앗지 않도록).
3. 새 모듈 `src/main/hotkey.js` — `createHotkey({ shortcut, onPress })`(`shortcut`은 Electron `globalShortcut` 주입, 시험에서는 가짜).
   - `apply(combo)`: 이전 등록 해제 → `toAccelerator`가 `null`이면 상태 `'off'`(빈 값) 또는 `'invalid'` → `shortcut.register(acc, onPress)`가 false면 `'taken'`(다른 프로그램이 이미 사용), 성공이면 `'ok'`. 상태를 반환하고 `state()`로도 읽음.
   - `suspend(on)`: 설정 서랍에서 키를 녹화하는 동안 잠시 해제(true)·다시 등록(false). 등록된 단축키는 시계 창 안에서도 키를 가로채므로 녹화 중에는 반드시 해제해야 합니다.
   - `dispose()`: `unregisterAll` 대신 **자기 것만** `unregister`.
4. `main.js` 배선:
   - 시작 때 `hotkey.apply(settings.returnHotkey)`, `settings:set`에 `returnHotkey`가 있으면 다시 `apply`. `will-quit`에서 `dispose()`.
   - `onPress`: 시계 창이 이미 포커스면 아무것도 안 함. 아니면 `foreground.cancelWait()`(실행 후 키 보내기·돌아오기 대기 취소 — 사용자가 직접 돌아왔으므로) 후 `bringToFront()`. 창 모드(전체화면/창)는 바꾸지 않습니다.
   - `hotkeysOn`(숫자패드 단축키 끔)과 **무관하게** 동작(끄려면 단축키를 비움).
   - IPC: `hotkey:state` → 현재 상태, `hotkey:suspend`(bool). preload에 `hotkeyState`, `hotkeySuspend` 노출.
5. 설정 서랍 '단축키' 탭 맨 위에 행 하나: '시계로 돌아오기' + 현재 조합 표시 + [녹화] [지우기] (슬롯의 `sendKeysRow`와 같은 녹화 UI 재사용, 녹화 시작 때 `hotkeySuspend(true)`, 끝·취소·서랍 닫힘·탭 이동 때 반드시 `hotkeySuspend(false)`).
   - 행 아래 작은 안내: 상태 `'taken'` → '다른 프로그램이 이미 쓰는 조합이라 등록하지 못했습니다', `'invalid'` → 'Ctrl·Alt·Win 중 하나와 함께 눌러 주세요'(이때 저장하지 않고 이전 값 유지), 평상시 → '시계가 켜져 있는 동안 다른 프로그램의 같은 단축키(예: 브라우저 방문 기록 Ctrl+H)는 동작하지 않습니다'.
6. 화면 아래 단축키 안내 줄(`buildLegend`)은 바꾸지 않습니다.

## B. 전체화면 끄기 버튼(모든 테마 좌하단)

1. `index.html`에 `#screenBtn`을 톱니(`#gear`, 우하단)의 **좌우 대칭**으로: `left:18px; bottom:18px`, 같은 크기·배경·`body.awake`일 때만 3초 보임·서랍 열리면 숨김. 테마 밖(앱 공통)이라 6개 테마 모두에 자동 적용.
2. 아이콘 두 벌(선 굵기·크기는 톱니와 같게): 전체화면일 때 '네 모서리가 안쪽으로'(전체화면 끄기), 창 모드일 때 '바깥으로'(전체화면). `aria-label`·`title` 3언어: '전체화면 끄기(작업 표시줄 보기)' / '전체화면으로'.
3. 동작: IPC `window:toggleFullscreen` → 메인이 전체화면이면 `setFullScreen(false)` 후 `maximize()`(작업 영역 = 작업 표시줄이 보이는 크기, 기본 창 틀 유지), 아니면 `setFullScreen(true)`. 메인은 `enter-full-screen`/`leave-full-screen` 때 `window` 이벤트 `{ fullscreen }`을 보내고 `app:init`에도 `fullscreen`을 넣어 버튼 아이콘을 맞춥니다. preload에 `toggleFullscreen`, `onWindow` 노출.
4. **상태 저장 안 함**: 설정 키를 만들지 않습니다. 앱을 켤 때마다 지금처럼 전체화면으로 시작.
5. 창 모드에서 스테이지는 기존 `fit()`(높이 900 기준 배율)로 맞습니다. 창 모드·전체화면 왕복 뒤에도 가장자리 띠·잘림이 없는지 확인.

## C. 구글 로그인 만료 시 쉬운 재로그인

현재: refresh token이 만료(`invalid_grant`)되면 토큰 파일을 지우지만 설정의 `people[].google.connected`는 다음 연결 조작 전까지 `true`로 남아 카드가 '연결됨'+'해제'만 보여, 해제→다시 로그인 두 단계를 거쳐야 하고 왜 끊겼는지도 안 보입니다.

1. `google.js`
   - 갱신(`grant_type=refresh_token`) 중 `invalid_grant` → 토큰 삭제는 그대로 하되 오류 코드를 **`'expired'`**로 구분(토큰 파일이 원래 없던 `needAuth`와 다름). 인증 코드 교환 중 `invalid_grant`는 지금처럼 실패.
   - `buildAuthUrl(client, { redirect, challenge, state, loginHint })`: `loginHint`가 있으면 `login_hint` 추가(`prompt=select_account consent`는 유지 — refresh token이 확실히 오도록).
   - `connect(id, { loginHint } = {})`.
2. 설정 사람 항목 `google`을 `{ connected, expired, account }`로 넓힙니다(`store.js` 정규화: `expired` bool, `account` 254자 이하 문자열, 없으면 `''`). `account`는 연결 성공 직후 `lists(id)`의 `primary` 캘린더 id(= 계정 이메일, `@` 포함일 때만)로 채웁니다(범위 추가 없음). `applyFlags()`는 `connected`만 갱신하고 `expired`·`account`는 보존해야 합니다.
3. 상태 전이(메인):
   - 동기화가 사람 p에서 `'expired'`를 받으면 → `google.expired = true`, `applyFlags`, 설정 푸시(`createSync`에 `onExpired(id)` 콜백 추가). `sync.js`의 `known()`에 `'expired'` 포함(백오프 없이 정상 주기, 사람별 격리 그대로).
   - `google:connect` 성공 → `expired = false`, `account` 갱신, 캘린더 선택·메모 목록은 **그대로 유지**, 즉시 갱신, 그리고 `bringToFront()`(브라우저에서 로그인을 마치면 시계가 다시 앞으로).
   - `google:disconnect`·사람 삭제 → `expired = false`, `account = ''`.
4. 설정 서랍 사람 카드:
   - `!connected && expired` → 상태 점을 경고색(설정 강조색 #e8a33d)으로, 문구 '로그인 만료 — 다시 로그인해 주세요'(+ `account`가 있으면 작게 그 주소), 주 버튼 '다시 로그인'(`googleConnect(id)`; 메인이 저장된 `account`를 `loginHint`로 씀). 기존 캘린더·메모 켜짐 상태와 선택은 그대로 보임.
   - 서랍을 열 때 만료된 사람이 있으면 **'연결' 탭으로 바로 열고** 그 카드를 보이게 스크롤.
5. 대시보드 상태 줄: `i18n.statusText`에 `'expired'` → '구글 로그인 만료 · 설정에서 다시 로그인'(3언어). 기존 `needAuth`와 같은 규칙(캘린더 쪽 한 줄, 사람 2명 이상이면 이름 접두). 그 사람이 캘린더를 끄고 메모만 켰으면 메모 쪽에서 같은 문구.
6. 근본 원인 안내: 7일마다 끊기는 것은 Google Cloud 콘솔 OAuth 동의 화면이 '테스트' 상태이기 때문입니다. `docs/setup.md`에 'Google Auth Platform → 대상(Audience) → 앱 게시(프로덕션으로)' 절차와 '확인되지 않은 앱' 경고 화면 통과 방법을 짧게 추가합니다(코드 변경 아님).

## D. 시험

새·바뀐 순수 함수와 모듈마다 `node:test` 추가(현재 시험 수 유지 + 추가):
- `toAccelerator`: 변환표, 수정키 없음·Shift만·깨진 값 `null`, Win→Super.
- `hotkey.js`(가짜 shortcut): ok/taken/invalid/off, 재적용 때 이전 것 해제, suspend/재개, dispose가 자기 것만 해제.
- `store`: `returnHotkey` 기본·정규화, `google.expired`·`account` 정규화.
- `google`: 갱신 중 `invalid_grant` → 코드 `'expired'` + 토큰 파일 삭제, `buildAuthUrl` `login_hint` 유무.
- `sync`: `'expired'`가 백오프를 걸지 않고 `onExpired(id)` 호출, 다른 사람 갱신에 영향 없음.
- `i18n`: `statusText` expired, 새 키 3언어 일치.
