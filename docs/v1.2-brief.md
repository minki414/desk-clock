# v1.2 작업 지시 — 화면 꽉 채움 · 설정창 디자인 · 자동 실행

설계: Opus · 구현: Sonnet · 2026-11-11 사용자 요청. 음력·절기는 하지 않습니다(사용자 결정).

## 1. 모든 테마 화면 꽉 채우기

현상: 스테이지가 1440×900 고정 + `min` 배율이라 16:9 화면에서 좌우 여백(레터박스)이 생깁니다. 바우하우스만 바탕이 단색이라 여백과 같은 색으로 보여 '꽉 찬 것처럼' 보이고, 나머지 5종은 그라디언트·안쪽 요소 배경 때문에 여백이 드러납니다.

결정: **스테이지 높이는 900 고정, 너비는 화면 비율에 맞춰 가변**으로 바꿉니다.
- `W = clamp(round(900 × innerWidth / innerHeight), 1200, 1800)`, 배율 `s = innerHeight / 900`. 16:10 → 1440, 16:9 → 1600, 3:2 → 1350.
- 스테이지에 `style.width = W + 'px'`과 CSS 변수 `--stage-w`를 설정하고 `resize` 때 다시 계산합니다. 1200·1800 범위를 벗어나는 극단 비율에서만 남는 여백은 지금처럼 바탕색으로 채웁니다.
- 테마 계약 변경(설계자 승인): 테마는 **고정 1440 가정을 버리고 스테이지 너비 100%에 맞춰 배치**합니다.
  - 바탕(그라디언트 포함)은 테마 루트(스테이지 전체)에 칠합니다.
  - 좌측 덩어리는 `left`, 우측 덩어리는 `right` 기준으로 고정하고, 남는 폭은 둘 사이 간격이 흡수합니다. 바우하우스처럼 3단 대칭인 테마는 `grid-template-columns: 330px 1fr 330px`처럼 가운데가 늘어나게 합니다.
  - 시계 지름·글자 크기는 높이 기준이라 바꾸지 않습니다.
  - 리시버는 본체(호두나무 옆판 포함)가 스테이지 폭 전체로 늘어나고 창·버튼 줄이 그 폭을 나눕니다.
  - 플립은 카드 두 장이 가운데에 모이고, 아래 정보 3단은 폭에 맞춰 퍼집니다.
  - 스탠바이는 시계 좌측·칸 우측 고정입니다.
- `tools/theme-preview.html`에 `w=` 파라미터(기본 1440)를 추가합니다. 6종 × 라이트/다크 × `w=1440,1600,1350`에서 겹침·잘림·어색한 빈 공간이 없어야 합니다. 이 화면들을 찍어서 직접 봅니다.
- 실제 창 확인: 전체화면 앱을 1920×1080에서 띄워 6종 모두 가장자리에 띠가 없는지 확인합니다.

## 2. 설정창 디자인

지금 서랍은 기능만 있습니다. 식탁 위 시계와 같은 결의, 조용하고 정돈된 설정 화면으로 다듬습니다.

- 형태: 오른쪽에서 밀려 나오는 서랍, 폭 520px(배율 적용 전 실제 픽셀 기준, 화면 높이 꽉), 열릴 때 뒤 화면은 `rgba(0,0,0,.35)`로 살짝 어둡게. 진입 0.28초 ease-out, 닫기 0.2초.
- 색: 어두운 중성 패널 #17171a, 구분선 #26262b, 본문 #ececef, 보조 #9a9aa3, 강조 하나 #e8a33d(바우하우스 노랑 계열). 밝은 모드 설정창은 만들지 않습니다(설정은 잠깐 여는 화면).
- 서체: Pretendard Variable. 제목 22px/600, 항목 이름 15px/500, 설명 13px 보조색.
- 구조: 상단 제목 '설정' + 닫기(×, 직접 그린 SVG). 그 아래 탭 4개(밑줄형): **화면 · 단축키 · 연결 · 정보**.
  - 화면: 테마 고르기(6개 썸네일 카드 2열, 카드 = 실제 테마 축소 이미지 + 이름, 선택 시 강조색 테두리 2px), 색 모드(라이트/다크/자동 분절 버튼), 야간 시간(시작·끝 시각), 야간 감광 토글 + 최소 밝기 슬라이더(0~30%), Windows 시작 시 자동 실행 토글.
  - 단축키: 숫자패드 단축키 토글(설명: '0·+·−·1~9를 함께 켜고 끕니다'), 웹 링크 브라우저(Brave/Chrome/Edge/기본 브라우저 분절 버튼), 슬롯 1~9 목록(행 = 번호 배지 + 이름 입력 + 종류[웹/프로그램] 분절 + 주소 또는 경로 입력 + 프로그램이면 '찾아보기' + '주소창 없는 창' 체크 + '실행해 보기' 작은 버튼). 빈 슬롯 행은 흐리게.
  - 연결: 구글(상태 문장 + 로그인/연결 해제 버튼, 클라이언트 파일 고르기, 표시할 캘린더 체크 목록, 메모 목록 선택), 날씨 위치(자동/직접 검색 + 검색 결과 목록), 감시할 서버(이름·주소 행 추가/삭제, 각 행에 현재 상태 점).
  - 정보: 버전, 설정 폴더 열기, 앱 종료(강조색 아닌 붉은 외곽선 버튼, 한 번 더 확인).
- 컨트롤: 토글은 36×20 둥근 스위치, 분절 버튼은 높이 34·반경 8, 입력칸 높이 38·반경 8·배경 #1f1f23, 포커스 링 2px 강조색. 스크롤바도 패널 색으로 테마(얇게). 모든 컨트롤 키보드 조작 가능.
- 테마 썸네일: `docs/theme-shots/<id>-<mode>.png`를 ffmpeg로 320×200(가변 폭 반영 후 다시 찍은 1440 기준)으로 줄여 `src/renderer/thumbs/<id>-light.webp`·`-dark.webp`로 넣고, 현재 색 모드에 맞는 쪽을 보여 줍니다.
- 문구는 합니다체, 상태는 명사형. 저장은 바꾸는 즉시(별도 저장 버튼 없음), 저장되면 항목 옆에 0.8초 '저장됨'.
- 확인: 각 탭 화면을 실제 창에서 찍어 직접 봅니다.

## 3. Windows 시작 시 자동 실행

- 설정 `autoStart`(기본 꺼짐). 켜면 `app.setLoginItemSettings({ openAtLogin: true, path: exe })`.
- **portable 주의**: portable exe는 실행할 때마다 임시 폴더에 풀려 `process.execPath`가 임시 경로입니다. 반드시 `process.env.PORTABLE_EXECUTABLE_FILE`(원래 exe 경로)을 쓰고, 없으면(개발 실행) 토글을 비활성화하고 '설치본에서만 쓸 수 있습니다' 안내.
- exe를 다른 폴더로 옮기면 등록 경로가 낡습니다. 앱 시작 때 켜져 있으면 현재 경로로 다시 등록합니다.
- 시작 직후 네트워크가 늦게 잡혀도 오류 없이 마지막 캐시를 보여 주고 백오프 재시도(이미 구현)로 회복되는지 확인합니다.
