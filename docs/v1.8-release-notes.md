# DeskClock 1.8.0

이번부터 설치형입니다. `DeskClock-Setup-1.8.0.exe`를 실행하면 설치가 끝납니다.
설정과 구글 연결은 같은 `%APPDATA%\DeskClock`을 사용하므로 그대로 이어집니다.
이전 portable exe는 지워도 됩니다. Windows 시작 시 자동 실행을 켜 두었다면 새 앱의 첫 실행 때 같은 DeskClock 항목을 새 경로로 덮어씁니다.

정보 탭에서 ‘업데이트 확인’과 ‘업데이트’를 누르면 새 버전을 내려받아 조용히 설치하고 다시 실행합니다. 타이머가 동작·일시정지·울림 중이면 끝난 뒤 다시 눌러 주세요. 앱 시작이나 주기적인 업데이트 확인은 하지 않습니다.

서명하지 않은 설치 파일이므로 처음 설치할 때 SmartScreen에서 ‘추가 정보 → 실행’을 선택해야 할 수 있습니다.
